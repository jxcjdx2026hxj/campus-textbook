# 校园二手教材流转平台

**课程**：AI应用开发：低代码与智能工具实践
**项目类型**：个人期中项目
**面向**：江西财经大学学生

---

## 一、项目简介

一个面向本校学生的轻量级二手教材流转平台，解决毕业季教材闲置、新学期买书贵的供需矛盾。采用「低代码框架 + 大模型 API」的技术路线，只做买卖双方的信息撮合，实际交易由双方线下当面完成。

---

## 二、运行方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动项目

```bash
streamlit run app.py
```

启动后浏览器访问 http://localhost:8501

### 3. 配置 AI 功能（可选但推荐）

1. 打开 https://platform.deepseek.com/ 注册账号
2. 在「API Keys」页面创建一个新的 Key
3. 复制 Key（sk- 开头）
4. 粘贴到页面左侧侧边栏的「DeepSeek API Key」输入框

> Key 会自动保存到本地 `config.json`，只需输入一次，重启后依然有效。

### 4. 如果不配置 AI Key

网站所有非 AI 功能（发布、浏览、筛选、求购、评价、管理）都可以正常使用，只有「AI智能匹配」「AI价格建议」「AI求购推荐」三个入口会提示需要配置 Key。

## 三、项目文件说明

| 文件 | 作用 |
|------|------|
| `app.py` | 主程序，包含所有页面逻辑、AI 调用、表单处理 |
| `database.py` | 数据库模块，负责建表和增删改查 |
| `config.py` | 配置文件读写，用于持久化保存 API Key |
| `textbooks.db` | SQLite 数据库文件，含 26 本在售教材和 8 条求购的示例数据 |
| `uploads/` | 存放用户上传的教材封面图片 |
| `requirements.txt` | 依赖清单 |
| `实验报告.md` | 课程实验报告 |
| `config.json` | 自动生成，保存 API Key（首次运行后产生） |

## 四、功能清单

### 首页
- 平台介绍 + 数据统计看板（在售教材数、求购信息数、已成交数、平均价格）

### 发布教材（卖家）
- 封面上传（可选），列表中显示封面缩略图
- 填写：教材名称、对应课程、售价、成色、所在校区、联系方式、学号（可选）、备注
- **AI 价格建议**：输入书名，AI 给出合理的二手售价参考
- 输入校验：教材名称、售价、联系方式为空时给出提示

### 发布求购（买家）
- 找不到书时可以发布求购需求
- 填写：想要的教材、对应课程、心理价位、成色要求、所在校区、联系方式
- **发布后自动列出匹配的在售教材卡片**（含封面、价格、联系方式），不用自己去翻
- 附 AI 推荐说明

### 浏览教材
- 标签页切换「在售教材」和「求购信息」
- 多维筛选：关键词搜索、课程筛选、价格区间、成色筛选、**校区筛选**
- 卡片展示：封面、书名、课程、价格、成色、校区、联系方式、卖家信誉评分

### AI 智能匹配
- 用自然语言描述需求（如"我想要一本高等数学的书，麦庐园"）
- 系统先列出匹配的教材卡片，再附 AI 推荐理由

### 我的发布
- 输入发布时填写的联系方式即可查询
- 三个标签页：「我卖的书」「我求的书」「我的评价」
- 支持标记已售出 / 重新上架 / 标记已找到 / 重新求购 / 删除
- 已售出的书可以直接发起评价

### 评价与信誉
- 交易完成后买家可给卖家打 1-5 星 + 文字评价
- 卖家列表展示平均评分和评价数量，降低交易风险
- 支持学号认证字段，增加身份可信度

## 五、技术栈

| 层次 | 技术选型 | 理由 |
|------|---------|------|
| 前端 | Streamlit | 低代码框架，无需写 HTML/CSS/JS，专注业务逻辑 |
| 数据库 | SQLite | 零配置、单文件，适合课程项目和小范围使用 |
| AI 能力 | DeepSeek API（deepseek-chat） | OpenAI 兼容格式，接入简单，有免费额度 |
| 文件存储 | 本地 uploads 目录 | 简化实现，无需对象存储 |

### AI 能力实现方式

三项 AI 功能都通过「把结构化数据拼进提示词，交给大模型做语义判断」实现：

1. **AI 价格建议**：传入书名和成色，要求模型只返回一个数字，再用正则提取
2. **AI 求购推荐**：传入求购需求 + 在售教材清单，要求模型挑出最匹配的 1-3 本并说明理由
3. **AI 智能匹配**：传入用户的自然语言需求 + 在售清单，让模型做语义匹配和推荐
